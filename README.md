## 结论先行

| # | 结论 | 关键证据 |
|---|---|---|
| 1 | **迁移学习是唯一显著的改进** | 5 折池化 **+0.2700 ± 0.0361**，3/3 种子全胜；单次划分 +0.2300，5/5 全胜 |
| 2 | **数据增强在这份数据上没帮助，甚至略拖后腿** | 三次对照方向一致为负（−0.003 ~ −0.02），胜率 0/5、1/3；训练 loss 反而从 0.267 升到 0.317 |
| 3 | **四个预训练模型打平，选型没有意义** | 全部落在 **0.9033 ~ 0.9233**，最大差距 2 张图；MobileNet 用 1/7 参数达到同样水平 |
| 4 | **从零训练确实学不出通用特征** | 池化 **0.6533**，5 个种子在 0.60~0.69 之间晃；单跑那次 0.80 是运气 |
| 5 | **20 张验证集会骗人** | ShuffleNet 单次划分 0.74 vs ResNet18 0.88（差 0.14），池化后只差 **0.0067（1 张图）** |

> 一句话：**这 100 张图撑不起"哪个模型更好"的结论，只撑得起"预训练比从零强"。**

## 数据集

```
data/
├── cat.1.jpg  ~ cat.50.jpg     50 张猫
└── dog.51.jpg ~ dog.100.jpg    50 张狗
```

| 项目 | 值 |
|---|---|
| 规模 | 100 张，猫 50 / 狗 50，严格平衡 |
| 标签来源 | **文件名**：含 `cat` → 0，否则 → 1（不需要标注文件） |
| 输入尺寸 | Resize 到 `224×224`，ImageNet 均值方差归一化 |
| 划分 | **80 训练 / 20 验证**，`seed=42` 固定，所有步骤共用同一份 |
| 划分方式 | 默认 `random_split`；`--split txt` 可复现指导书原版 `random.sample` 索引划分 |

> ⚠️ **两种划分是两份不同的数据**。指导书第一步用 txt 索引、后面几步用 `random_split`，
> 它们抽到的 20 张验证图并不相同——这是原文一个隐藏的不公平点。
> 本项目默认统一成同一份划分，想看原版写法加 `--split txt`（结果 0.75，默认划分 0.80）。

## 快速开始

### 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.10+（实测 3.12.14） |
| PyTorch | ≥ 2.0（实测 2.13.0+cu130） |
| GPU | 可选。实测 RTX 5070 Laptop 12 GB，CPU 也能跑但慢 |
| 磁盘 | 代码 + 数据约 5 MB，权重缓存约 310 MB，产物约 1 GB |

### 安装

```bash
git clone https://github.com/Echo-wwz/cat_dog.git
cd cat_dog

pip install -r requirements.txt
# 有 GPU 时建议先按 https://pytorch.org 的官方命令装 CUDA 版 torch，再装其余依赖
```

### 跑起来

```bash
python check_env.py         # ① 自检：依赖 / GPU / 数据集张数 / 权重缓存
python run_all.py --dry-run # ② 只看计划，不执行（推荐先看一眼）
python run_all.py all       # ③ 六步 + 消融 + 交叉验证，约 15~20 分钟
python run_all.py app       # ④ 启动 Gradio 拍照小程序（前台阻塞，Ctrl+C 退出）
```

**首次运行会自动下载 4 个预训练权重**（约 310 MB）到 `torch_cache/hub/checkpoints/`。
`config.py` 会把该目录设为 `TORCH_HOME`，之后换机器只要拷文件夹即可离线跑。

> 实测环境：RTX 5070 Laptop（12 GB）/ torch 2.13.0+cu130。
> 纯 CPU 也能跑，但 AlexNet 30 轮会很慢，建议配 `--epochs 5`。

### 常用命令

```bash
python run_all.py --list                  # 列出全部任务编号
python run_all.py single                  # 只跑六步单次运行（约 4 分钟）
python run_all.py single --only 1 4       # 只跑第一步和第四步
python run_all.py ablation                # 多随机种子消融（约 6 分钟）
python run_all.py crossval                # 5 折交叉验证（约 9 分钟）
```

每个脚本也能独立运行，公共参数 `--epochs / --lr / --batch-size / --device / --seed / --data-dir`：

```bash

python step2_pretrained.py --finetune        # 解冻全部层微调（lr 自动降到 1e-5）
```

## 实验设计

### 技术路线

```
                        ┌─────────────────────────────┐
   100 张猫狗图  ──────► │ 统一 80/20 划分（seed=42）   │
                        └──────────────┬──────────────┘
                                       │
        ┌──────────────┬───────────────┼───────────────┬──────────────┐
        ▼              ▼               ▼               ▼              ▼
   ① 从零训练     ② 迁移学习      ③ 数据增强      ④ 模型对比     ⑤ 保存推理
   AlexNet        ImageNet 权重   ResNet18+增强   4 个骨干       best + 全量
   46.8M 参数     冻结 / 微调     5 / 15 轮       参数量差 9 倍   91% 准确率
        │              │               │               │              │
        └──────────────┴───────────────┴───────────────┴──────────────┘
                                       │
                        ┌──────────────▼──────────────┐
                        │ ⑥ Gradio 拍照小程序（部署）  │
                        └─────────────────────────────┘
                                       │
              ┌────────────────────────┴────────────────────────┐
              ▼                                                 ▼
    加餐① 10 配置 × 5 种子消融                        加餐② 6 配置 × 3 种子 × 5 折
    （判断差异是不是噪声）                            （把验证集从 20 张提到 100 张）
```

### 控制变量

横向对比要成立，必须只有**一个**变量在动。全流程固定：

| 维度 | 取值 | 说明 |
|---|---|---|
| 数据划分 | 同一份 80/20，`seed=42` | `common.get_loaders` 唯一入口 |
| 输入尺寸 | `224×224` + ImageNet 归一化 | 验证集永远用干净的 Resize + Normalize |
| 损失函数 | `CrossEntropyLoss` | 二分类直接用 2 维输出，不额外套 Sigmoid |
| 优化器 | `Adam` | 学习率按实验类型区分（见下表） |
| batch size | 16 | 显存不足可降到 8 / 4 |
| 随机性顺序 | `set_seed → 建模型 → 建 DataLoader → 训练` | 见 [可复现性协议](#可复现性协议) |

学习率不是随便定的，**必须与对应脚本默认值一致**，否则就不是"同一个实验"：

| 实验类型 | lr | 理由 |
|---|---|---|
| 从零训练 / 预训练冻结 | `1e-4` | 指导书取值，小数据上更稳 |
| ResNet18 / MobileNet / ShuffleNet 冻结 | `1e-3` | 只训分类头，可以给大一点 |
| 全解冻微调 | `1e-5` | 保护预训练特征，避免灾难性遗忘 |

## 六步详解

### ① 从零训练 AlexNet

**目的**：建立基线——不给任何先验知识，模型能学到什么程度。

**网络结构**（224×224 输入）

| 层 | 配置 | 输出 |
|---|---|---|
| Conv1 | 11×11 / stride 4 / pad 1，96 通道 | 54×54×96 |
| MaxPool | 3×3 / stride 2 | 26×26×96 |
| Conv2 | 5×5 / pad 2，256 通道 | 26×26×256 |
| MaxPool | 3×3 / stride 2 | 12×12×256 |
| Conv3 | 3×3 / pad 1，384 通道 | 12×12×384 |
| Conv4 | 3×3 / pad 1，384 通道 | 12×12×384 |
| Conv5 | 3×3 / pad 1，256 通道 | 12×12×256 |
| MaxPool | 3×3 / stride 2 | 5×5×256 |
| Flatten | — | 6400 |
| FC | 6400 → 4096，Dropout 0.5 | 4096 |
| FC | 4096 → 4096，Dropout 0.5 | 4096 |
| FC | 4096 → 2 | 2 |

- 权重初始化 `xavier_uniform_`，参数量 **46.76 M**。
- `padding=1`（而非 AlexNet 原版的 2）正好让 224 输入落到 `5×5`，即 `256×5×5 = 6400`——
  这是这个手写版能跑通的关键，写成 `padding=2` 会在第一个全连接层炸掉。
- 30 轮，`lr=1e-4`，batch 16。

**结果**：单跑 `0.80`，5 种子 **0.68 ± 0.10**，5 折池化 **0.6533**。

**观察**：训练 loss 掉到 **0.0070**，验证准确率却只有 0.68——80 张训练图被完整记住了，
泛化能力没跟上。这就是小数据从零训练最典型的样子。

---

### ② 迁移学习：加载 ImageNet 权重

**目的**：验证"预训练特征可以迁移"这个假设。

**换头的正确姿势**（也是指导书最容易写错的地方）：

```python
official = models.alexnet(weights=models.AlexNet_Weights.DEFAULT)
net = AlexNetManual(num_classes=1000)        # 1. 先建 1000 类的完整结构
net.load_state_dict(official.state_dict())   # 2. 形状完全一致，strict=True 也能过
net.classifier[6] = nn.Linear(4096, 2)       # 3. 再换成 2 类，新头随机初始化
```

> 指导书原版是 `load_state_dict(official.state_dict(), strict=False)` 直接往 2 类模型上灌。
> **`strict=False` 只豁免"缺键/多键"，不豁免形状不匹配**——
> `fc: 512→2` vs `512→1000` 会直接抛 size mismatch。必须先建 1000 类结构。

| 模式 | 冻结范围 | 可训练参数 | 结果 |
|---|---|---|---|
| 冻结（默认） | 只训 `classifier` | **54.5 M** / 57.0 M | 单跑 0.95，5 种子 0.91 ± 0.05，池化 **0.9233** |
| 微调（`--finetune`） | 全部层，`lr=1e-5` | 57.0 M | 5 种子 0.86 ± 0.07 |

**观察**：AlexNet 的"冻结"其实还训着 5400 万参数——因为它的全连接层占了 95% 的体积。
这和 ResNet18 冻结（只训 1026 个参数的 `fc`）完全不是一个量级，看耗时对比时要记住这点。

**反直觉的是：微调（0.86）比冻结（0.91）更差。** 100 张图 + `lr=1e-5` 也足以让预训练特征
被小数据带偏，而冻结版本连这个风险都没有。

---

### ③ 数据增强

**目的**：检验"增强能提升泛化"这个在教科书里几乎默认成立的结论。

训练集 transform（验证集永远只有 Resize + Normalize）：

| 操作 | 参数 | 意图 |
|---|---|---|
| `RandomResizedCrop` | 224，scale 0.7~1.0 | 让模型不依赖固定构图 |
| `RandomHorizontalFlip` | p=0.5 | 猫狗左右对称，安全 |
| `ColorJitter` | 亮度/对比度/饱和度 0.2 | 抵抗光照差异 |
| `RandomRotation` | ±10° | 抵抗拍摄角度 |
| `RandomErasing` | p=0.5，scale 0.02~0.2（可选） | 逼模型别只看局部 |

**结果**：5 轮增强 **0.88 ± 0.08**，不加增强 **0.90 ± 0.08**；15 轮时 0.90 vs 0.91。
**三次对照方向全部为负**，胜率 0/5、1/3。

**观察**：训练 loss 从 **0.267 升到 0.317**，任务确实变难了，但验证准确率没涨。
猫狗二分类太简单，ImageNet 特征已经覆盖了这些变化，增强只增加了难度、没增加信息量。
**这不是"有效但测不出"，是确实没帮助。**

---

### ④ 模型横向对比

**目的**：在同等训练预算下比较不同骨干，同时回答"参数量差 9 倍有没有区别"。

| 模型 | 总参数 | 冻结后可训练 | 单次划分 5 种子 | 5 折池化 | 秒/折 |
|---|---|---|---|---|---|
| ResNet18 | 11.18 M | 1.0 K | 0.8800 ± 0.0758 | 0.9133 | 10.0 |
| MobileNetV3-Small | 1.52 M | 2.0 K | 0.8900 ± 0.0548 | 0.9100 | 13.9 |
| ShuffleNetV2-x1.0 | 1.26 M | 2.0 K | 0.7400 ± 0.0822 | 0.9033 | 14.2 |
| EfficientNet-B0 | 4.01 M | 2.6 K | —（未跑消融） | — | — |

**观察**

- MobileNetV3 用 **1/7** 的参数达到同一水平，工程上是明确的胜利——但和 ResNet18 的
  0.0033 差距在噪声内，**不能说谁更准**。
- ShuffleNet 单次划分看着差 0.14，池化后只差 1 张图。
  详见 [关键发现 3](#3-粒度陷阱shufflenet-的差距是假的)。
- ShuffleNet 训练 loss **0.6591**，比其他模型高一个数量级——它的通道数太少，
  冻结特征对这份数据的判别力确实弱一些，头部学不动。

## 结果总览

单次运行（`seed=42`）只作参考——**验证集 20 张，1 个样本 = 5%**。
真正可信的是 5 种子均值和 5 折池化。

| 步骤 | 关键改动 | 单跑（seed=42） | 5 种子均值 ± std | 5 折池化（100 张） |
|---|---|---|---|---|
| ① 从零训练 | AlexNet，随机权重，30 轮 | 0.80 | 0.68 ± 0.10 | **0.6533** |
| ② 预训练冻结 | ImageNet 权重，只训分类头 | 0.95 | 0.91 ± 0.05 | **0.9233** |
| ③ 数据增强 | ResNet18 + 增强，5 轮 | 0.90 | 0.88 ± 0.08 | 0.9100 |
| ④ 三模型对比 | 各 5 轮 | 0.90 / 0.90 / 0.75 | 0.88 / 0.89 / 0.74 | 0.9133 / 0.9100 / 0.9033 |
| ⑤ 保存 + 推理 | best + 全量 100 张 | 0.90；全量 91% | — | — |
| ⑥ 部署 | Gradio 摄像头 | 可用（HTTP 200） | — | — |

## 关键发现

### 1. 迁移学习：唯一站得住的结论

| 对照 | 单次划分（5 种子） | 5 折池化（3 种子） | 判定 |
|---|---|---|---|
| **预训练 − 从零** | **+0.2300 ± 0.1151**，胜率 **5/5** | **+0.2700 ± 0.0361**，胜率 **3/3** | ✅ 显著 |
| 增强 − 不增强（5 轮） | −0.0200 ± 0.0447，0/5 | −0.0033 ± 0.0153，1/3 | ❌ 噪声内 |
| 增强 − 不增强（15 轮） | −0.0100 ± 0.0548，1/5 | — | ❌ 噪声内 |
| RandomErasing | +0.0100 ± 0.0224，1/5 | — | ❌ 噪声内 |
| 冻结 vs 微调（同为 5 轮） | +0.0500 ± 0.0612，3/5 | — | ❌ 噪声内 |
| MobileNet vs ResNet18 | — | 0.0000 ± 0.0100，1/3 | 完全一致 |
| ShuffleNet vs ResNet18 | — | −0.0067 ± 0.0115，0/3 | 略低，幅度极小 |

**五组对照里只有"迁移学习"是真的。** 指导书那张六步对比表里 0.85 / 0.90 / 0.95 的差异，
绝大多数是 20 张验证集的抽样噪声。

### 2. 数据增强为什么没用

三个理由，从强到弱：

1. **任务太简单**。猫狗二分类，ImageNet 预训练特征已经覆盖了翻转、缩放、光照这些变化，
   增强带来的不变性冗余了。
2. **数据量太小**。80 张训练图，增强后每轮看到的仍是这 80 张的变换版本，
   信息量上限没变，只是把优化问题变难了（loss 0.267 → 0.317）。
3. **三次对照方向一致为负**。这不是随机波动，是稳定的轻微负效应。

> 反过来说：如果换成细粒度分类（比如猫的品种），或者训练图只有 10 张，
> 增强很可能就有用了。**结论只在这份数据上成立。**

### 3. 粒度陷阱：ShuffleNet 的差距是假的

单次划分下 ShuffleNet 看着明显更差（0.74 vs 0.88，差 0.14）。把 100 张图每张都预测一次后：

| 配置 | 单次划分（20 张） | 5 折池化（100 张） | 变化 |
|---|---|---|---|
| ResNet18 + 增强 | 0.88 ± 0.08 | 0.9100 | +0.03 |
| ShuffleNetV2 + 增强 | 0.74 ± 0.08 | 0.9033 | **+0.16** |
| *两者差距* | *−0.14* | *−0.0067* | *缩小约 20 倍* |

它只是恰好在那 20 张上多错了 5 张。**验证集越小，越容易把噪声读成结论。**

### 4. 从零训练的真实水平低于指导书下限

第一步单跑 0.80 落在指导书预期区间（0.65~0.80）里，但 5 个种子只有 1 次摸到 0.80，
其余在 0.55~0.75；池化后 **0.6533**。

也就是说，那次 0.80 是运气。真实水平在区间下沿之外——这反而更有力地支持了
"小数据集从零训练学不出通用特征"这个论断。

### 5. 一个额外的观察：波动主要来自"哪张图落在哪折"

5 折交叉验证里，**折间标准差 0.06~0.08**，而**种子间标准差只有 0.01~0.03**。

这说明：模型训练本身相当稳定，真正让数字上下跳的是**数据划分**。
所以"换个 seed 结果就变了"的现象，本质是样本太少，而不是训练不稳定。

## 消融实验

### 为什么需要它

验证集 20 张 → 1 个样本 = 5%。0.85 / 0.90 / 0.95 之间只差 1 个样本，换种子就可能翻转。
要判断"增强到底有没有用"，必须：

1. 跑**多个种子**看 `mean ± std`；
2. 做**配对比较**（同一划分下逐种子相减），而不是比两个均值。

```bash
python run_all.py ablation      # 7 配置 × 5 种子 + 4 配置 × 5 种子，约 6 分钟
python step7_ablation.py --seeds 42 1 2 --configs 4_resnet18_aug 3_resnet18_noaug
```

### 完整矩阵（10 配置 × 5 种子 = 50 次训练）

种子固定为 `[42, 1, 2, 3, 4]`，所有配置共用同一份划分。

| 配置 | 轮数 | lr | 增强 | 均值 | std | min–max | 训练 loss | 逐种子 | 秒/次 |
|---|---|---|---|---|---|---|---|---|---|
| `1_scratch_alexnet` | 30 | 1e-4 | 无 | 0.6800 | 0.1037 | 0.55–0.80 | 0.0070 | .80/.70/.75/.55/.60 | 17.1 |
| `2_alexnet_frozen` | 5 | 1e-4 | 无 | 0.9100 | 0.0548 | 0.85–0.95 | 0.0015 | .95/.95/.85/.95/.85 | 2.6 |
| `3_resnet18_noaug` | 5 | 1e-3 | 无 | 0.9000 | 0.0791 | 0.80–1.00 | 0.2668 | .90/1.00/.95/.80/.85 | 2.2 |
| `4_resnet18_aug` | 5 | 1e-3 | basic | 0.8800 | 0.0758 | 0.80–1.00 | 0.3166 | .90/1.00/.85/.80/.85 | 3.1 |
| `5_resnet18_aug_erase` | 5 | 1e-3 | +Erasing | 0.8900 | 0.0822 | 0.80–1.00 | 0.3781 | .95/1.00/.85/.80/.85 | 3.3 |
| `6_mobilenet_aug` | 5 | 1e-3 | basic | 0.8900 | 0.0548 | 0.80–0.95 | 0.2868 | .90/.95/.90/.90/.80 | 3.1 |
| `7_shufflenet_aug` | 5 | 1e-3 | basic | 0.7400 | 0.0822 | 0.60–0.80 | 0.6591 | .75/.60/.80/.75/.80 | 4.6 |

### 配对比较（同划分、同种子，逐对相减）

| 对照 | Δ mean ± std | 前者更好的种子 | 判定 |
|---|---|---|---|
| **迁移学习（预训练 − 从零）** | **+0.2300 ± 0.1151** | **5 / 5** | ✅ 显著 |
| 数据增强（aug − noaug） | −0.0200 ± 0.0447 | 0 / 5 | ❌ 无差异 |
| 数据增强 @15 轮 | −0.0100 ± 0.0548 | 1 / 5 | ❌ 无差异 |

| 冻结 vs 微调（同为 5 轮） | +0.0500 ± 0.0612 | 3 / 5 | ❌ 无差异 |

`step7_ablation.py` 的判据是：`|Δ| < 0.05` 记作"无显著差异"。
0.05 正好是 20 张验证集里的 **1 个样本**——低于这个数，讨论方向都没意义。

## 5 折交叉验证

### 原理

单次 80/20 划分只有 20 张验证图，分辨率 5%。K 折让**每张图恰好被预测一次**：

```
5 折 × 每折 20 张 = 100 个预测  →  分辨率 1%（比单次划分细 5 倍）
```

做法：按类别**分层**切 5 折（保证每折猫狗比例都是 10:10），轮流留一折当验证集、
其余 4 折训练，最后把所有验证预测**池化**在一起算准确率。

```bash
python run_all.py crossval                                   # 6 × 3 × 5 = 90 次训练，约 9 分钟
python step8_crossval.py --folds 10                          # 更细
python step8_crossval.py --seeds 42 1 --configs 3_resnet18_noaug 4_resnet18_aug   # 加快
```

### 结果（3 种子：42 / 1 / 2）

| 配置 | 池化准确率 | ± std | min–max | 逐种子 | 各折 std | 秒/折 |
|---|---|---|---|---|---|---|
| 从零训练 AlexNet | 0.6533 | 0.0473 | 0.60–0.69 | .69/.67/.60 | 0.0767 | 54.5 |
| **AlexNet 预训练冻结** | **0.9233** | 0.0252 | 0.90–0.95 | .92/.95/.90 | 0.0623 | 10.9 |
| ResNet18 无增强 | 0.9133 | 0.0115 | 0.90–0.92 | .92/.90/.92 | 0.0640 | 10.0 |
| ResNet18 + 增强 | 0.9100 | 0.0100 | 0.90–0.92 | .92/.91/.90 | 0.0712 | 14.3 |
| MobileNetV3-S + 增强 | 0.9100 | 0.0100 | 0.90–0.92 | .92/.90/.91 | 0.0471 | 13.9 |
| ShuffleNetV2 + 增强 | 0.9033 | 0.0058 | 0.90–0.91 | .90/.91/.90 | 0.0667 | 14.2 |

> 每折都是 20 张（等分），所以**池化准确率 = 各折准确率的平均**，数值上完全相等。
> 但两者的意义不同：池化是"100 个预测里的正确率"（分辨率 1%），
> 各折均值仍是"5 个 5% 精度数字的平均"。

### 配对比较（基于池化准确率，3 个种子）

| 对照 | Δ 池化准确率 | 胜率 | 判定 |
|---|---|---|---|
| **迁移学习（预训练 − 从零）** | **+0.2700 ± 0.0361** | **3/3** | ✅ **显著** |
| 数据增强（aug − noaug） | −0.0033 ± 0.0153 | 1/3 | 噪声内 |
| MobileNet vs ResNet18 | 0.0000 ± 0.0100 | 1/3 | 完全一致 |
| ShuffleNet vs ResNet18 | −0.0067 ± 0.0115 | 0/3 | 略低，幅度极小 |

### 交叉验证推翻了单次划分的一个结论

| 配置 | 单次划分（20 张） | 5 折池化（100 张） | 差异 |
|---|---|---|---|
| ResNet18 + 增强 | 0.88 ± 0.08 | 0.9100 | +0.03 |
| ShuffleNetV2 + 增强 | 0.74 ± 0.08 | 0.9033 | **+0.16** |
| *两者差距* | *−0.14* | *−0.0067* | *缩小约 20 倍* |

**结论**：四个预训练模型全部落在 **0.90–0.92**（最大差距 2 张图），
**模型选型在这份数据上没有意义**；只有**迁移学习**是唯一站得住的结论。

## 统计口径：怎么读这些数字

**两套分辨率，别混用。**

| 方法 | 验证样本 | 分辨率 | 用途 |
|---|---|---|---|
| 单次划分（80/20） | 20 张 | **5%**（1 样本 = 5%） | 六步实验、消融主表 |
| **5 折池化** | 100 张 | **1%**（1 样本 = 1%） | **最终结论以此为准** |

由此推出三条读表规则：

1. **差值小于 1 个样本（单次 0.05 / 池化 0.01）不要下结论。**
2. **比均值更该看"胜率"**。5 个种子里赢 5 次 vs 赢 3 次，含义完全不同——
   前者是系统性优势，后者可能只是运气好。
3. **`std` 是种子间波动，不是置信区间。** 它告诉你"换个 seed 结果能飘多远"，
   正好也是判断"两个配置的差距是否可信"的尺子。

一个现成的反面教材：`3_resnet18_noaug` 的 5 个种子是
`.90 / 1.00 / .95 / .80 / .85`——**同一个配置，最好和最差差 0.20（4 张图）**。
在这种波动下，去比较 0.88 和 0.90 谁更好，纯属自娱自乐。

## 可复现性协议

所有脚本遵守同一条顺序，**同一个 seed 才能跑出同一个结果**：

```
set_seed(seed) → 构建模型 → 构建 DataLoader → 训练（每轮验证一次）
```

### 三条容易踩的规则

1. **`train_and_eval()` 不自己播种。** 调用方负责在构建模型前 `set_seed()`。
   函数内部再播一次种，会导致模型初始化用一个随机状态、训练又换一个，无法复现。
2. **构建模型必须在构建 DataLoader 之前。** `nn.init.xavier_uniform_` 和 DataLoader 的
   shuffle 都消耗全局随机数，顺序变了结果就变。
3. **每轮必须验证一次。** DataLoader 每个迭代器都会用全局随机数生成 `base_seed`，
   少迭代一次（比如训练循环里不跑验证），从第 2 轮起 shuffle 顺序就分叉——
   实测同一个 seed 会跑出 **0.80 vs 0.75**。

第 3 条可以用 `_diag_rng.py` 现场验证：

```bash
python _diag_rng.py        # 输出"每轮验证"与"不验证"两条分支的最终结果
```

### 自检方法

消融矩阵里 `seed=42` 那一格，应当**精确等于**该脚本单独运行的结果：

| 步骤 | 单跑 | 消融矩阵 seed=42 | 对齐 |
|---|---|---|---|
| ① 从零训练 | 0.80 | 0.80 | ✅ |
| ② 预训练冻结 | 0.95 | 0.95 | ✅ |
| ③ 数据增强 | 0.90 | 0.90 | ✅ |
| ④ ResNet18 | 0.90 | 0.90 | ✅ |
| ⑥ MobileNet | 0.90 | 0.90 | ✅ |
| ⑦ ShuffleNet | 0.75 | 0.75 | ✅ |

对不上，就说明随机性约定被破坏了。

## 踩过的坑

### 指导书里 9 处照抄会报错的地方（已全部修正）

| # | 位置 | 原文 | 后果 | 修正 |
|---|---|---|---|---|
| 1 | 1.2 / 完整代码 | `class AlexNet(nn.Module)` | **缺冒号且类体没写**，只是占位符 | 补全整个类 |
| 2 | 第三步 | `from step1_scratch import ResNet18Manual` | **悬空引用**，那个类根本没定义 | 移到 `models_manual.py` 并正确导入 |
| 3 | 第三步 | `load_state_dict(..., strict=False)` | **strict=False 不豁免形状不匹配**，fc 512→2 vs 512→1000 必崩 | 先建 1000 类 → 加载 → 换头 |
| 4 | 第四步 | 只有 `import torch.nn as nn`，却用了 `torch.save` | `NameError` | 补 `import torch` |
| 5 | 第一步 | `random.sample` 前不播种 | 每次划分都变，"控制变量"无从谈起 | 划分前 `random.seed(seed)` |
| 6 | 全流程 | 第一步用 txt 索引，后面用 `random_split` | 两份不同的数据，横向对比不公平 | 统一 `common.get_loaders` |
| 7 | 第三步 | 增强逻辑可能作用到验证集 | 验证指标虚高 | 训练/验证用两套 transform |
| 8 | 第四步 | `build_model` 无未知模型名兜底 | 名字打错静默出错 | 加 `KeyError` 明确报错 |
| 9 | 第五步 | `models.resnet18(weights=None)` 写死 | 训好的 AlexNet 权重无法推理 | 加 `--model`，支持 6 种架构 |

### 自己踩的坑（更值得记）

| 坑 | 现象 | 根因 | 修正 |
|---|---|---|---|
| 权重静默覆盖 | 跑完任务 `1` 再跑 `1b`，准确率从 0.80 变 0.75，之后推理全错 | 两种划分写同一个文件名 | 按划分分文件：`step1_alexnet_scratch{,_txt}.pth` |
| 消融数字对不上 | 从零训练算成 0.52，比单跑低 0.28 | 配置表漏写 `lr`，走了 1e-3（正确 1e-4，差 10 倍） | 配置表里 `epochs` / `lr` 必须显式写出 |
| 同 seed 不同结果 | 0.80 vs 0.75 | 训练循环里少跑一次验证，DataLoader 迭代次数变了 | 每轮强制验证一次，`_diag_rng.py` 固化诊断 |
| 缓存路径多一层 | 设了 `TORCH_HOME` 还重新下载 | `TORCH_HOME` 是 `hub` 的**父目录**；`torch.hub.set_dir()` 则不带 `hub` | 用 `TORCH_HOME`，别混用 `set_dir` |

## 常见问题

**Q：权重文件为什么不在仓库里？**

GitHub 单文件硬上限 100 MB，本项目 `.pth` 有 178~233 MB；用 Git LFS 的话 795 MB 会吃掉
免费额度（1 GB）的 78%。权重几分钟就能重新训练，预训练权重首次运行自动下载，所以不入库。

**Q：第一次跑卡在下载预训练权重？**

网络不通就手动下载，**文件名必须一模一样**（含哈希后缀），放进 `torch_cache/hub/checkpoints/`：

| 文件 | 地址 |
|---|---|
| `alexnet-owt-7be5be79.pth` | `https://download.pytorch.org/models/alexnet-owt-7be5be79.pth` |
| `resnet18-f37072fd.pth` | `https://download.pytorch.org/models/resnet18-f37072fd.pth` |
| `mobilenet_v3_small-047dcff4.pth` | `https://download.pytorch.org/models/mobilenet_v3_small-047dcff4.pth` |
| `shufflenetv2_x1-5666bf0f80.pth` | `https://download.pytorch.org/models/shufflenetv2_x1-5666bf0f80.pth` |

**Q：想把权重缓存换到别处？**

设 `CATDOG_TORCH_HOME`（或 `TORCH_HOME`），指向 `torch_cache` 这一层。注意：

| 方式 | checkpoints 实际落在 |
|---|---|
| `CATDOG_TORCH_HOME=D:\别处\torch_cache` | `D:\别处\torch_cache\hub\checkpoints\` |
| `TORCH_HOME=D:\别处\torch_cache` | `D:\别处\torch_cache\hub\checkpoints\` |
| 代码里 `torch.hub.set_dir(r"D:\别处\torch_cache")` | `D:\别处\torch_cache\checkpoints\` ← **少一层** |

优先级（实测）：`CATDOG_TORCH_HOME` > 项目内 `torch_cache` > `TORCH_HOME` > `XDG_CACHE_HOME` > `~/.cache`。
`python check_env.py` 会打印实际生效目录和四个权重是否齐全。

**Q：换自己的数据集？**

把图片放进一个目录，文件名含 `cat` 判为 0、其余判为 1（`common.FileNameDataset` 的规则），然后：

```bash
python step4_compare.py --data-dir "D:/my_dataset"
# 或设环境变量 CATDOG_DATA
```

**Q：显存 / 内存不够？**

调小 `--batch-size`（默认 16，可降到 8 或 4）。100 张图在 12 GB 上完全够用，
真正的瓶颈是单通道内存而不是显存。

**Q：手机连不上 Gradio？**

① 手机和电脑必须同一 Wi-Fi；② Windows 防火墙放行 Python（首次启动弹窗勾"专用网络"）；
③ 用脚本打印的局域网 IP，不要用 `127.0.0.1`。

**Q：想快速验收，不想等？**

```bash
python step4_compare.py --epochs 2
python step5_train_save.py --epochs 2
python run_all.py single --only 1 4
```
